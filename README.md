# Student Skill Swap Platform

**Designed & Developed by Believe Nasiru**

A modern, frontend web application where students can create profiles, list skills they can offer, and specify skills they want to learn. The platform allows students to browse peers, request skill swaps, and contact each other directly via WhatsApp to arrange the exchange.

## 🚀 Live Demo
> **Link:** `https://believenasiru25-del.github.io/believenasiru/`

## ✨ Features
- **Student Registration:** Includes Matric Number, Date of Birth, Department, Faculty, Level, Gender, and Phone Number.
- **Profile Picture Upload:** Students can upload a profile picture with a live preview before submitting.
- **Personal Dashboard:** View your skills, bio, and manage incoming/outgoing swap requests.
- **Browse & Search:** Search for other students by name, department, or specific skills.
- **Skill Swap Requests:** Send, accept, or decline swap requests directly within the platform.
- **WhatsApp Integration:** A built-in WhatsApp button that opens a pre-filled message directly to the developer (Believe Nasiru) for support or inquiries.
- **Fully Responsive:** Beautiful, mobile-friendly UI designed with modern CSS.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (Single Page Application architecture).
- **Database / Storage:** Browser `localStorage` (Data is saved locally on the user's device).
- **Hosting:** GitHub Pages.

## 📂 How to Run Locally
Since this is a single-file frontend application, no installation or server is required:
1. Clone or download the repository.
2. Ensure the file is saved as `index.html`.
3. Double-click `index.html` to open it in any modern web browser (Chrome, Safari, Edge).

## 🌐 How to Deploy on GitHub Pages
1. Push the `index.html` and `README.md` files to a public GitHub repository.
2. Go to the repository **Settings**.
3. Click on **Pages** on the left sidebar.
4. Under "Build and deployment", select **Deploy from a branch**.
5. Choose the **main** branch and the **/ (root)** folder, then click **Save**.
6. My site will be live at `https://believenasiru25-del.github.io/believenasiru/` in a few minutes.

## 📝 Assignment Note
This project was built as a frontend demonstration of a Skill Swap platform. Because it utilizes `localStorage` for data persistence, it does not require a backend server. For a multi-user production environment, the `DB` object in the script can be easily swapped out for a REST API or Firebase backend without changing the UI.
